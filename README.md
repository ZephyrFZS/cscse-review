# cscse-review · 留服专业复核材料助手

留学生留服复核救命锦囊✨第一次认证多半是国外专业直译，考公考编 / 入职却要国内一级学科？开源 Skill 帮你整理理由 + 个人陈述 + 课程对照，本硕博都能用；材料是草稿，交之前自己再过一遍。

说人话：留服**第一次认证**时，专业栏常见做法是把国外专业名**直接译成中文**，不一定带国内目录里的**一级学科 / 专业学位类别**等正式表述。可很多人后面要**考公考编、企事业单位入职、岗位专业审核**等，对方往往认的是国内那套名称——这就需要走留服**复核**，申请补充或调整专业领域表述。本工具就是给这类已经拿到认证结果、准备去复核的人用的；不是帮你第一次办认证，也不是改姓名证件号那种笔误。装到 **Cursor / Codex / Claude Code** 里，它能一步步带着你把「为什么要改」「怎么表述诉求」「国外课和国内同层次培养方案怎么对照」理清楚，并产出可粘贴进系统的复核理由、个人陈述草稿和附件提醒。

正式一点说：这是一个开源小工具包（在上述三个客户端里都叫 **Skill**，可以理解成「给 AI 用的专用说明书」），专帮整理留服「国外学历学位认证**复核**」里与**专业领域 / 专业名称**相关的材料，覆盖本科、硕士、博士。是否符合某次招考或入职的专业要求，以用人单位规则为准，本工具不打包票。

> **这不是留服官方工具，也不代表留学服务中心的审查标准或意见。不保证复核通过。AI 也可能写错或说满，交件前请你自己核对。**

## 它做什么

| 做（你可能正需要的） | 不做（请别用错） |
|----------------------|------------------|
| 在「国外专业直译」基础上，申请补充 / 调整为教育部目录内的**专业领域**（硕博多为一级学科 / 专业学位类别；本科对照本科专业目录） | 改姓名、证件号等**写错字 / 填错信息** |
| 帮你写复核理由、个人陈述，并整理「国外课程 ↔ 国内同类培养」对照 | 改**学习地点、是不是合作办学、怎么上课**这类标注 |
| 按本科 / 硕士 / 博士分别整理，并提醒你要准备哪些附件 | 第一次申请认证、查学历真假；也不代替招考单位做「能不能报」的认定 |

**目标名称怎么写（别混）：**

- **硕士 / 博士（常见）：** `目录正式名（国外修读专业的中文直译）`  
  例如：`计算机科学与技术（信息技术）`
- **本科：** 一般直接用教育部《本科专业目录》里的**专业中文名**（不要套用上面「一级学科 + 括号」那套硕博写法，也不要把「在证书上显示专业代码」当目标）

说明：留服认证书上一般写的是**专业领域 / 名称**，**通常看不到**国内那种学科代码（如 0812、080901）。本工具也**不会承诺**证书上会出现这些代码。

## 适用谁

- 已经拿到留服认证，证书上多半是**国外专业直译**，但因考公考编、入职填表、岗位专业审核等，需要国内**一级学科 / 专业领域**等正式表述，准备申请**复核**的人  
- 电脑上已经能正常使用 **Cursor、Codex 或 Claude Code** 之一（需要能跟 AI 对话；本工具本身免费，但这些软件是否收费以各产品为准）  
- 国外学历层次是：**本科、硕士、博士**

如果你几乎不用电脑命令行也没关系：下面「安装」给了最简单的做法；命令行只是给会用的人省事。

## 怎么用

### 1. 安装（第一次用要做一次）

**更省事：直接让 AI 帮你装**

本 Skill 同时支持 **Cursor、Codex、Claude Code**。在你正在用的那个工具里新开对话，把本仓库链接丢给它，并说一句：

> 请把 https://github.com/ZephyrFZS/cscse-review 安装到我当前这个客户端的 skills 目录（Cursor / Codex / Claude Code 任选我正在用的），装好后确认能看到 `SKILL.md`。如果我同时用好几个，也请一并装上或告诉我怎么共用。

让它帮你下载/放到正确文件夹即可。  
**若 AI 提示没有权限、装失败：** 不用硬撑，改用下面的「自己手动装」。  
装成功后建议**新开一轮对话**再开始做复核（有的软件要重启后才能稳定识别新 Skill）。

**自己手动装（推荐小白）：**

1. 打开本仓库页面，点绿色的 **Code** → **Download ZIP**，下载后解压。  
2. 解压后文件夹名可能是 `cscse-review-main` 之类，请**改名为** `cscse-review`。  
3. 把整个 `cscse-review` 文件夹挪到你正在用的软件对应位置（没有就自己新建；多个软件都要用，就各放一份，或复制一份过去）：

| 你用的软件 | 放到这里 |
|------------|----------|
| Cursor | Mac：用户目录下的 `.cursor/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.cursor\skills\cscse-review\` |
| Codex | Mac：`.codex/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.codex\skills\cscse-review\` |
| Claude Code | Mac：`.claude/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.claude\skills\cscse-review\` |

> Mac 小提示：用户目录就是访达侧边栏里带房子图标的那个；`.cursor` / `.codex` / `.claude` 以点开头，默认可能被隐藏。可用菜单「前往 → 前往文件夹…」，粘贴例如 `~/.cursor/skills` 再回车。

装好后，确认文件夹里能看到一个叫 `SKILL.md` 的文件就行。

**会用终端的人也可以这样装（三个客户端示例）：**

```bash
# Cursor
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.cursor/skills/cscse-review

# Codex
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.codex/skills/cscse-review

# Claude Code
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.claude/skills/cscse-review
```

### 2. 准备材料（有什么交什么，没有就先跳过）

**一般要有：** 留服认证书、国外完整成绩单；有学位证更好（方便核对学校名、学位名）。  

**如果读国外学位时抵免过别的学校学分：** 录取 / 转学分证明，以及被抵免那份学历的成绩单、毕业证 / 学位证。  

**如果学制明显比常见学制短：** 能证明学制或就读情况的材料（学校发的学制说明、成绩单附页等；有的学校叫 AHEGS、Diploma Supplement，就是「学历成绩补充说明」一类文件）。  

**如果是博士、课特别少：** 论文题目或摘要、院系 / 项目介绍网页等（别硬凑一张空课表）。

把 PDF / 照片准备好，对话里按 AI 提示提供即可（注意别发到公开 Issue）。

### 3. 打开 AI，直接跟它说

在 **Cursor / Codex / Claude Code** 里新开一次对话，用自然语言说明即可，例如：

- `用 cscse-review 帮我做留服专业复核`
- `我要申请留服认证复核，补充专业领域并调整专业名称`

（有的客户端也支持输入 `/cscse-review`，没有也没关系，把上面的话发给 AI 即可。）

然后按它的提问一步步答：你是本 / 硕 / 博 → 想改成什么专业领域名称 → 对一下材料和课程 → **生成前它会给你看风险摘要，你确认后再出文书**。

### 4. 你会得到什么

- 一段可以复制进留服网页的**复核原因**  
- 《个人陈述申请及相关证明材料》草稿（常见是 Word，你再另存成 PDF）  
- 一份附件清单和上传注意（默认：以前交过的材料一般不用再传；**以留服网页当时提示为准**）

文件一般保存在你指定的文件夹，或当前项目里的 `复核材料/`。  
**请务必自己通读后再提交**；对比材料里不要写成绩，也不要把内部用的「强 / 中」字样留在交件里。

### 5. 可选：本地脚本（进阶，不会可完全跳过）

下面只给熟悉电脑命令、想自己生成 Word 的人看。**不会敲命令不影响正常使用**，跟 AI 聊天做完就够了。

```bash
cd /path/to/cscse-review/scripts
pip install python-docx pyyaml   # 按需安装
# 先复制示例再改成你的内容（不要直接改仓库里的虚构样例当交件）
cp case.example.yaml case.yaml
python3 check_consistency.py case.yaml --allowed 你的课号1,你的课号2
python3 build_review_docx.py case.yaml -o 个人陈述申请及相关证明材料.docx
```

脚本只是帮忙排版；交上去之前请自己再通读一遍，尤其对照 `templates.md` 里的写法，**别没检查就提交**。

## 风险提示（请务必阅读）

1. **复核次数有限：** 认证结果出来后，通常 **12 个月之内只能复核 1 次**，且免费；提交前请自己再看一眼官方最新规定。  
2. **不保证过：** 材料再齐也不保证复核成功；证书最后怎么写，以留服出具的结果为准。  
3. **材料要真实：** 不能编造课号、课程简介、目录里没有的专业名；出问题由申请人自己负责。  
4. **转学分 / 学制偏短：** 要如实说明在发证学校实际读了什么，别藏着掖着。  
5. **对照表别硬凑：** 内部整理时可能用「强 / 中」这类标记方便自己看，**不要写进最终交件**；对不上就写「—」。对比材料里也**不要写成绩**。  
6. **以网页提示为准：** 上传什么格式、要不要重传已交材料，**以留服网上服务大厅当时页面为准**。  
7. **注意隐私：** 不要把真实证件号、护照、完整成绩单发到公开仓库或 Issue 里。

官方入口（以网站当前页面为准）：[留服网上服务大厅](https://zwfw.cscse.edu.cn/)
