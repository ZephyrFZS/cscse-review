## 它是什么

留服**第一次认证**时，专业栏常见做法是把国外专业名**直接译成中文**，不一定写成国内目录里的**一级学科 / 专业学位类别**等正式表述。很多人之后要**考公考编、企事业单位入职、岗位专业审核**，对方往往认国内那套名称——需要走留服**复核**，申请补充或调整专业领域表述。

本仓库提供一个可安装的 **Skill**（可以理解成「给 AI 用的专用说明书」）。装进 Cursor / Codex / Claude Code 后，跟 AI 对话即可逐步整理材料。

| 入口 | 用途 | 主要交付 |
| --- | --- | --- |
| `/cscse-review` | 留服**专业领域 / 专业名称**相关复核 | 复核原因文稿、个人陈述草稿、课程/培养对照思路、附件清单与上传提醒 |

> **这不是留服官方工具，也不代表留学服务中心的审查标准或意见。不保证复核通过。AI 也可能写错，交件前请你自己核对。**

## 安装

本 Skill 同时支持 **Cursor、Codex、Claude Code**。装好后建议**新开一轮对话**再开始使用。

### 更省事：让 AI 帮你装

在你正在用的客户端里新开对话，发送：

```text
请把 https://github.com/ZephyrFZS/cscse-review 安装到我当前这个客户端的 skills 目录
（Cursor / Codex / Claude Code 任选我正在用的），装好后确认能看到 SKILL.md。
如果我同时用好几个，也请一并装上或告诉我怎么共用。
```

若 AI 提示没有权限、装失败：改用下面的手动方式。

### 手动安装（推荐小白）

1. 打开本仓库 → 绿色 **Code** → **Download ZIP**，解压。  
2. 文件夹名可能是 `cscse-review-main`，请**改名为** `cscse-review`。  
3. 整文件夹放到对应路径（没有就新建；多客户端就各放一份或复制一份）：

| 平台 | 安装位置 | 装好后 |
| --- | --- | --- |
| Cursor | Mac：`~/.cursor/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.cursor\skills\cscse-review\` | 新建 Agent 对话，输入下方「典型用法」 |
| Codex | Mac：`~/.codex/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.codex\skills\cscse-review\` | 同上 |
| Claude Code | Mac：`~/.claude/skills/cscse-review/`<br>Windows：`C:\Users\你的用户名\.claude\skills\cscse-review\` | 同上 |

> Mac：用户目录是访达侧边栏带房子图标的文件夹；以点开头的目录可能被隐藏，可用「前往 → 前往文件夹…」粘贴 `~/.cursor/skills` 等路径。  
> 装好后确认目录内有 `SKILL.md`。

### 终端安装（会用命令行时）

```bash
# Cursor
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.cursor/skills/cscse-review

# Codex
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.codex/skills/cscse-review

# Claude Code
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.claude/skills/cscse-review
```

### 可选：本地脚本（进阶，可跳过）

不会敲命令不影响正常使用。需要自己生成 Word 时：

```bash
cd /path/to/cscse-review/scripts

cp case.example.yaml case.yaml   # 先复制示例再改成你的内容
python3 check_consistency.py case.yaml --allowed 你的课号1,你的课号2
python3 build_review_docx.py case.yaml -o 个人陈述申请及相关证明材料.docx
```

## 第一次使用：适不适合你

| 当前情况 | 建议 |
| --- | --- |
| 已拿到留服认证，证书上多半是国外专业**直译**，因考公考编 / 入职需要国内**一级学科 / 专业领域**等正式表述 | 用 `/cscse-review` |
| 还没办过认证，想第一次申请认证 | **不要用**本 Skill，走留服首次认证流程 |
| 只想改姓名、证件号等笔误，或改学习地点 / 合作办学标注 | **不要用**本 Skill，按留服系统对应复核入口自行办理 |
| 想确认某次招考「能不能报」 | 本工具**不代替**招录单位认定；只帮整理复核材料 |
| 学历层次是本科 / 硕士 / 博士 | 可以；流程会按层次分支 |
| 只会用豆包等国内聊天 AI、不会用 Cursor 等 | 当前版本需先装到 Cursor / Codex / Claude Code；后续可能补充「粘贴提示词」方案 |

## `/cscse-review`：留服专业复核材料

**重要提醒：本项目禁止编造课号、课程简介、目录外专业名，或把「强一致 / 完全等同」等满格措辞写进交件。复核通常 12 个月内仅 1 次且免费，提交即占用机会。材料为申请人自助草稿，不保证复核通过，也不保证认证书版式（一般不展示学科/专业代码）。请只基于真实成绩单与公开培养方案整理；最终交件须本人通读确认。本 Skill 不会替你登录留服系统或代为提交。**

`/cscse-review` 协助整理与 **专业名称、一级学科 / 专业学位类别归属** 相关的留服复核材料：逐步确认学历层次与目标名称，整理复核理由与个人陈述结构，并对照国外修读内容与国内同层次培养方案（课程或培养环节）。默认产出写到你指定的目录或工作区 `复核材料/`。

### 做 / 不做

| 做 | 不做 |
| --- | --- |
| 在「国外专业直译」基础上**补充**专业领域（写法多为「目录名（原专业直译）」加括号，不是整段抹掉重写） | 改姓名、证件号等**写错字 / 填错信息** |
| 写复核理由、个人陈述，整理「国外课程 ↔ 国内同类培养」对照 | 改**学习地点、合作办学、授课模式**等标注 |
| 按本科 / 硕士 / 博士分别整理，并提醒附件 | 首次认证、查验真伪；代替招考单位认定报考资格 |

### 目标名称怎么写（本/硕/博同一套路：加括号，不是直接替换）

常见写法：`目录正式名（国外修读专业的中文直译）`

| 层次 | 括号外 | 例子 |
|------|--------|------|
| 本科 | 《本科专业目录》里的**专业类**或**专业名** | `计算机类（智能科技与服务）` |
| 硕士 / 博士 | 一级学科或专业学位类别 | `计算机科学与技术（信息技术）` |

可观察的本科结果：首次认证往往只有「××学士学位」；复核后常在保留原学位表述的同时，**增加**「专业领域为『目录名（原专业直译）』」。不要把目标理解成「把原专业整段改成光秃秃的目录名」。也不要把「在证书上显示专业代码」当目标——认证书上**通常看不到**国内代码（如 080901），本工具也不承诺会打印代码。

### 建议准备的材料

| 情况 | 建议准备 |
| --- | --- |
| 所有人 | 留服认证书、国外完整成绩单；有学位证更好（核校名 / 学位名） |
| 有转学分 / 抵免 | 录取或转学分证明；被抵免学历的成绩单、毕业证 / 学位证 |
| 学制明显偏短 | 学制或就读说明（有的学校叫 AHEGS、Diploma Supplement 等） |
| 博士且课很少 | 论文题目或摘要、院系 / 项目公开页等（别硬凑空课表） |

对话里按 AI 提示提供 PDF / 照片即可。**不要**把真实证件与完整成绩单发到公开 Issue。

### 典型用法

```text
/cscse-review

我已拿到留服认证，证书上是国外专业直译。
因考公 / 入职需要补充国内一级学科（专业领域），请按 cscse-review 帮我整理复核材料。
学历层次：硕士
先确认目标名称怎么写，再逐步要材料；生成前先给我风险摘要，我确认后再出文书。
```

也可以不用斜杠，直接说：

```text
用 cscse-review 帮我做留服专业复核
我要申请留服认证复核，补充专业领域并调整专业名称
```

然后按提问逐步确认：本科 / 硕士 / 博士 → 目标专业领域名称 → 材料与课程对照 → **生成前风险摘要确认** → 文书。

### 你会得到什么

- 可复制进留服网页的**复核原因**文稿  
- 《个人陈述申请及相关证明材料》草稿（常见 Word，再另存 PDF）  
- 附件清单与上传注意（默认：首次已交材料一般不必重传；**以留服网页当时提示为准**）

交件前请自己通读；对比材料里**不要写成绩**，也不要把内部用的「强 / 中」字样留在交件里。

官方入口（以网站当前页面为准）：[留服网上服务大厅](https://zwfw.cscse.edu.cn/)

## 事实边界

使用本 Skill 时请遵守：

- **不保证**复核通过，不保证认证书最终版式或「打印代码」；
- 专业名称须来自教育部**最新**公示目录，禁止臆造目录外名称；
- 国外课号须能在成绩单或录取 / 转学分证明原文找到；不编造课描；
- 对应牵强写「—」，不强凑；陈述禁用「高度一致」「完全等同」等满格措辞；
- 对比材料**不写成绩**；「强 / 中 / 弱」仅内部整理，**不进交件**；
- 转学分占比高或学制偏短时，如实说明在颁证院校的修读情况；
- 成功标准句用「**申请**将…调整为… / **申请**补充专业领域为…」，不用「已变更为…」「认定成功为…」；
- 不在公开仓库或 Issue 中上传真实证件号、护照、完整成绩单等隐私；
- 是否符合某次招考或入职专业要求，以用人单位规则为准；
- 流程、模板、选校顺序均为经验整理，可能过时；提交前请核对官方办法与最新学科专业目录。

本项目由作者业余维护，**与教育部留学服务中心无隶属、无授权、无合作关系**。使用所产生的任何损失，维护者不承担责任。**建议**向留服提交前确认已理解上述风险，并对材料内容自行负责。
