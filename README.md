# cscse-review · 留服专业复核材料助手

面向 **教育部留学服务中心（留服 / CSCSE）**「国外学历学位认证**复核**」场景的 Agent Skill：帮你整理**专业领域 / 专业名称**相关的复核理由、个人陈述、境内外培养方案与课程（或培养环节）对照材料。

> **这不是留服官方工具，也不代表留学服务中心的审查标准或意见。**

---

## 它做什么

| 做 | 不做 |
|----|------|
| 补充**专业领域**（一级学科 / 专业学位类别等目录内名称） | 姓名、证件号等**信息笔误**更正 |
| 调整 / 更正认证结果中的**专业或学科表述** | **学习地点、合作办学、授课模式**等标注类复核 |
| 按本 / 硕 / 博整理对照材料与上传提醒 | 首次认证申请、学历查验、非留服业务 |

常见目标写法（硕 / 博）：

`目录正式名（国外修读专业的中文直译）`  
例如：`计算机科学与技术（信息技术）`

说明：留服认证书通常体现的是**专业领域 / 名称**表述，**一般不展示**国内学科或专业代码（如 0812、080901）。本工具也不承诺证书会「打印代码」。

---

## 适用谁

- 已取得留服认证结果，准备在系统里申请**复核**的申请人  
- 使用 **Cursor Agent / OpenAI Codex / Claude Code** 等支持 Agent Skills 的环境  
- 学历层次：国外**学士 / 本科、硕士、博士**

## 怎么用（给使用者）

### 1. 安装 Skill

将本仓库放到本机 skills 目录（任选或同时安装）：

| 客户端 | 建议路径 |
|--------|----------|
| Cursor | `~/.cursor/skills/cscse-review/` |
| Codex | `~/.codex/skills/cscse-review/` |
| Claude Code | `~/.claude/skills/cscse-review/` |

可用克隆或符号链接，保证目录内包含 `SKILL.md`。

```bash
# 示例：克隆到 Cursor skills
git clone <本仓库 URL> ~/.cursor/skills/cscse-review

# 若希望 Codex / Claude 共用同一份
ln -sfn ~/.cursor/skills/cscse-review ~/.codex/skills/cscse-review
ln -sfn ~/.cursor/skills/cscse-review ~/.claude/skills/cscse-review
```

### 2. 准备材料（按需）

**通常需要：** 留服认证书、国外完整成绩单；建议有学位证便于核对校名 / 学位名。  

**如有转学分：** 录取 / 转学分证明、抵免来源学历成绩单与毕业证学位证。  

**学制明显短于标准学制：** 学制或就读证明（如 AHEGS、Diploma Supplement 等）。  

**博士且课很少：** 论文题目或摘要、院系 / 项目公开页等（否则不宜硬做空壳课表）。

### 3. 在对话里启动

新开 Agent 对话，任选一种说法：

- `用 cscse-review 帮我做留服专业复核`
- `/cscse-review`
- `我要申请留服认证复核，补充专业领域并调整专业名称`

按助手提问逐步确认：学历层次 → 目标专业领域名称 → 材料与课程对照 → **生成前风险摘要确认** → 文书。

### 4. 你会得到什么

- 可粘贴到系统的**复核原因**文稿  
- 《个人陈述申请及相关证明材料》结构（Word / 再另存 PDF）  
- 附件清单与上传注意（默认不重传已交材料；**以留服系统当时提示为准**）

产出目录一般由你指定，或工作区下的 `复核材料/`。

### 5. 可选：本地脚本

```bash
cd /path/to/cscse-review/scripts
pip install python-docx pyyaml   # 按需
python3 check_consistency.py case.yaml --allowed CODE1,CODE2
python3 build_review_docx.py case.yaml -o 个人陈述申请及相关证明材料.docx
```

脚本只是排版辅助；**终稿须按 `templates.md` 核对**，不要未审就提交。

自动化测试（虚构案例）：见 [`scripts/tests/README.md`](scripts/tests/README.md)。

## 风险提示（请务必阅读）

1. **复核机会有限：** 认证结果出具之日起通常 **12 个月内仅可复核 1 次**，且免费；提交前请自行核对官方最新规则。  
2. **不保证结果：** 材料再完整也不保证复核通过；证书最终如何记载以留服出具结果为准。  
3. **材料真实性：** 不得编造课号、课程简介、目录外专业名；虚假材料后果由申请人自负。  
4. **转学分 / 短学制：** 转学分占比高或学制明显偏短时，须如实说明在颁证院校的修读情况，勿回避。  
5. **对应表克制：** 课程「强 / 中」仅为内部工作分级，**不会、也不应**印在交件上；牵强对应应写「—」。  
6. **系统优先：** 上传格式、是否重传已交材料，**以留服网上服务大厅当时页面提示为准**。  
7. **隐私：** 不要把含真实证件号、护照、成绩单全文的个案提交进公开仓库或 Issue。

官方入口（请以网站当前页面为准）：[留服网上服务大厅](https://zwfw.cscse.edu.cn/)
