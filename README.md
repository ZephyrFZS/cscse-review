# cscse-review · 留服专业复核材料助手

留学生留服复核救命锦囊✨专业领域对不上别慌！开源 Skill 帮你整理理由 + 个人陈述 + 课程对照，本硕博都能用，干货直接抄作业。

说人话：面向已经拿到留服（CSCSE）认证结果、但觉得**专业名称 / 专业领域写得不对劲**、准备去申请**复核**的留学生；不是帮你第一次办认证，也不是改姓名证件号那种笔误。装到 Cursor / Codex / Claude 这类 AI 编程工具里，它能一步步带着你把「为什么要改」「怎么表述诉求」「国外课和国内同层次培养方案怎么对照」理清楚，并产出可粘贴进留服系统的复核理由、个人陈述草稿，以及附件上传提醒——省得自己从零抠模板、对着空文档干瞪眼。

正式一点说：这是一个开源小工具包（在 Cursor 等软件里叫 **Skill**，可以理解成「给 AI 用的专用说明书」），专帮整理留服「国外学历学位认证**复核**」里与**专业领域 / 专业名称**相关的材料，覆盖学士 / 本科、硕士、博士。

> **这不是留服官方工具，也不代表留学服务中心的审查标准或意见。不保证复核通过。**

---

## 它做什么

| 做（你可能正需要的） | 不做（请别用错） |
|----------------------|------------------|
| 申请补充 / 调整认证书上的**专业领域**或**专业名称**（要对照教育部目录里的正式叫法） | 改姓名、证件号等**写错字 / 填错信息** |
| 帮你写复核理由、个人陈述，并整理「国外课程 ↔ 国内同类培养」对照 | 改**学习地点、是不是合作办学、怎么上课**这类标注 |
| 按本科 / 硕士 / 博士分别整理，并提醒你要准备哪些附件 | 第一次申请认证、查学历真假、或其他非留服业务 |

常见目标写法（硕 / 博）：

`目录正式名（国外修读专业的中文直译）`  
例如：`计算机科学与技术（信息技术）`

说明：留服认证书上一般写的是**专业领域 / 名称**，**通常看不到**国内那种学科代码（如 0812、080901）。本工具也**不会承诺**证书上会出现这些代码。

## 适用谁

- 已经拿到留服认证结果，准备在网上申请**复核**的人  
- 电脑上会用 **Cursor**、**Codex** 或 **Claude Code** 这类带 AI 助手的工具（把本工具装进去后，跟 AI 聊天就能用）  
- 国外学历层次是：**本科（学士）、硕士、博士**

如果你几乎不用电脑命令行也没关系：下面「安装」给了最简单的做法；命令行只是给会用的人省事。

## 怎么用

### 1. 安装（第一次用要做一次）

**更省事：直接让 AI 帮你装**

如果你已经在用 Cursor（或其他带 Agent 的工具），可以新开对话，把本仓库链接丢给它，并说一句：

> 请把 https://github.com/ZephyrFZS/cscse-review 安装到我的 skills 目录，装好后确认能看到 `SKILL.md`。

让它帮你下载/放到正确文件夹即可（装完建议新开一轮对话再开始做复核）。不会手动操作的，优先用这一招。

**自己手动装（推荐小白）：**

1. 打开本仓库页面，点绿色的 **Code** → **Download ZIP**，下载后解压。  
2. 把解压出来的文件夹**改名为** `cscse-review`。  
3. 整文件夹挪到下面其中一个位置（没有就自己新建文件夹）：
| 你用的软件 | 放到这里（Mac 举例） |
|------------|----------------------|
| Cursor | 用户目录下的 `.cursor/skills/cscse-review/` |
| Codex | 用户目录下的 `.codex/skills/cscse-review/` |
| Claude Code | 用户目录下的 `.claude/skills/cscse-review/` |

> Mac 小提示：用户目录就是访达侧边栏里带房子图标的那个；`.cursor` 这类名字以点开头的文件夹默认可能被隐藏，可用访达菜单「前往 → 前往文件夹…」直接粘贴路径进去。

装好后，确认文件夹里能看到一个叫 `SKILL.md` 的文件就行。

**会用终端的人也可以这样装：**

```bash
# 把仓库下载到 Cursor 的 skills 目录（把网址换成本仓库地址）
git clone https://github.com/ZephyrFZS/cscse-review.git ~/.cursor/skills/cscse-review
```

### 2. 准备材料（有什么交什么，没有就先跳过）

**一般要有：** 留服认证书、国外完整成绩单；有学位证更好（方便核对学校名、学位名）。  

**如果读国外学位时抵免过别的学校学分：** 录取 / 转学分证明，以及被抵免那份学历的成绩单、毕业证 / 学位证。  

**如果学制明显比常见学制短：** 能证明学制或就读情况的材料（学校发的学制说明、成绩单附页等；有的学校叫 AHEGS、Diploma Supplement，就是「学历成绩补充说明」一类文件）。  

**如果是博士、课特别少：** 论文题目或摘要、院系 / 项目介绍网页等（别硬凑一张空课表）。

### 3. 打开 AI，直接跟它说

新开一次对话，任选一句：

- `用 cscse-review 帮我做留服专业复核`
- `/cscse-review`
- `我要申请留服认证复核，补充专业领域并调整专业名称`

然后按它的提问一步步答就行：你是本 / 硕 / 博 → 想改成什么专业领域名称 → 对一下材料和课程 → **生成前它会给你看风险摘要，确认后再出文书**。

### 4. 你会得到什么

- 一段可以复制进留服网页的**复核原因**  
- 《个人陈述申请及相关证明材料》草稿（常见是 Word，你再另存成 PDF）  
- 一份附件清单和上传注意（默认：以前交过的材料一般不用再传；**以留服网页当时提示为准**）

文件一般保存在你指定的文件夹，或项目里的 `复核材料/`。

### 5. 可选：本地脚本（进阶，不会可完全跳过）

下面只给熟悉电脑命令、想自己生成 Word 的人看。**不会敲命令不影响正常使用**，跟 AI 聊天做完就够了。

```bash
cd /path/to/cscse-review/scripts
pip install python-docx pyyaml   # 按需安装
python3 check_consistency.py case.yaml --allowed CODE1,CODE2
python3 build_review_docx.py case.yaml -o 个人陈述申请及相关证明材料.docx
```

脚本只是帮忙排版；交上去之前请自己再通读一遍，尤其对照 `templates.md` 里的写法，**别没检查就提交**。

## 风险提示（请务必阅读）

1. **复核次数有限：** 认证结果出来后，通常 **12 个月之内只能复核 1 次**，且免费；提交前请自己再看一眼官方最新规定。  
2. **不保证过：** 材料再齐也不保证复核成功；证书最后怎么写，以留服出具的结果为准。  
3. **材料要真实：** 不能编造课号、课程简介、目录里没有的专业名；出问题由申请人自己负责。  
4. **转学分 / 学制偏短：** 要如实说明在发证学校实际读了什么，别藏着掖着。  
5. **对照表别硬凑：** 内部整理时可能用「强 / 中」这类标记方便自己看，**不要写进最终交件**；对不上就写「—」。  
6. **以网页提示为准：** 上传什么格式、要不要重传已交材料，**以留服网上服务大厅当时页面为准**。  
7. **注意隐私：** 不要把真实证件号、护照、完整成绩单发到公开仓库或 Issue 里。

官方入口（以网站当前页面为准）：[留服网上服务大厅](https://zwfw.cscse.edu.cn/)
